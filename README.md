## 🔭 Featured Project

### [Cortex — Code Intelligence Platform](https://github.com/gavinspet/Cortex-Code-Intelligence-Platform)
A production-style **C++20** backend that analyses public GitHub repositories asynchronously.
Submit a repo → the **Drogon** REST API queues a job on **Redis Streams** → a **C++ worker pool** clones and scans it → results are stored in **MySQL** and shown in a React dashboard.
Persistent job state, failure recovery, observability, Docker and GitHub Actions CI.

`C++20` · `Drogon` · `Redis Streams` · `MySQL` · `React` · `Docker` · `GitHub Actions`
