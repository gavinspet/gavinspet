## 🔭 Featured Projects

### [Spectra Vision — C++ REST API Server](https://github.com/gavinspet/spectra-vision)
A modern **C++17** REST/JSON API server built around clean architecture — Strategy, Factory,
Singleton, and Dependency Injection patterns with SOLID design and RAII-based resource management.
`cpp-httplib` · `nlohmann/json` · `CMake` · `Docker` · deployed live.

### 🚧 Cortex — Code Intelligence Platform *(in progress)*
A distributed **C++20** platform: async job orchestration over Redis Streams with a lock-free
worker pool, backpressure, and per-job failure isolation. `Drogon` REST APIs · `Prometheus` +
`OpenTelemetry` · `Docker` · CI/CD. *(Repo goes public soon.)*
